# Ban / Kick - базовая модерация

## Назначение
Стандартные модераторские наказания: бан (постоянное исключение с сервера, временный бан не поддерживается) и кик (разовое выгнание - пользователь не попадает в бан-лист, повторный вход не запрещён). Удаление истории сообщений пользователя при бане не поддерживается (нет аналога `delete_message_days`) - при необходимости выполняется отдельно, стандартным функционалом Discord.

## Команды
| Команда | Синтаксис | Права |
|---|---|---|
| `/kick` | `target:<упоминание или id> reason:<текст>` | Модератор; причина **обязательна** |
| `!kick` | `<user_id> <reason>` | Модератор; позиционные аргументы через один пробел |
| `/ban` | `target:<упоминание или id> reason:[опционально]` | Модератор; причина **опциональна** |
| `!ban` | `<user_id> [reason]` | Модератор; позиционные аргументы через один пробел |
| `/unban` | `target:<упоминание или id> reason:<текст>` | Модератор; причина обязательна |
| `!unban` | `<user_id> <reason>` | Модератор; позиционные аргументы через один пробел |

Именование параметров `target`/`reason` - общая конвенция для всех slash-команд бота, см. [base.md](../base.md) "Команды - общие конвенции".

Все команды доступны и как slash-, и как префиксные (`!`), аналогично [mute.md](mute.md). Подчиняются общей проверке иерархии ролей - см. [rules.md](../rules.md) "Роли и права" ("нельзя наказать роль выше/равную своей").

Примеры:
```
!ban 1094877821857435680 3.2, твинк каскада
!unban 618135355169964062 есть смс (100 шт)
```

## Формат ответа бота
Отправляется embed туда же, где вызвана команда: `/kick` - в **`#бот-команды`** (вместе с `mute`/`unmute`); `/ban`/`/unban` - в отдельный канал **`#баны`**. Оба канала - см. [base.md](../base.md) "Каналы, завязанные на бота".
- полоса слева - **зелёная**;
- author эмбеда = ник + аватар модератора, вызвавшего команду (как в [mute.md](mute.md));
- блок **Причина**: текст причины; для `/ban` (единственная из трёх, где причина опциональна) - если не указана, `"Причина не указана"` (тот же текст-заглушка, что и в [mute.md](mute.md)).

Текст по командам:
| Команда | Текст в embed |
|---|---|
| `/kick` | `@упоминание кикнут с сервера` |
| `/ban` | `@упоминание забанен. Помянем.` |
| `/unban` | `@упоминание разбанен. Возрадуемся!` |

## DM-уведомления
Нет.

## Логирование
Бот пишет embed в канал вызова (`#бот-команды` для кика, `#баны` для бана/разбана) только тогда, когда действие выполнено через его собственную команду из чата.

Системные оповещения о бане через нативное контекстное меню Discord (в обход бота) или о разбане через встроенный список забаненных - это отдельный вебхук Discord, не связанный с ботом Коннор.

## Хранимые данные
Не требуется - источник истины для бана/кика - сам факт бана/кика в Discord (Discord ban list для `/ban`).

## Обработка ошибок (точные тексты)
| Ситуация | Ответ бота |
|---|---|
| `/unban` на пользователе, которого нет в списке банов | `Не нашел пользователя <@упоминание> в списке банов` |
| `id`/упоминание невалидно или не резолвится, при `/ban`, `/kick` или `/unban` | `Укажите пользователя или id` (тот же текст, что и в аналогичном случае у [mute.md](mute.md)/[anti.md](anti.md)) |
| Корректный `id`, но цель уже отсутствует на сервере, при `/ban` | `Укажите пользователя или id. Также возможно пользователь уже отсутствует на сервере` |
| Цель - роль выше/равна инициатору, или цель - бот, при `/ban` | `Вы не можете банить старших или эквивалентных по роли или ботов` |
| Цель - роль выше/равна инициатору, или цель - бот, при `/kick` | `Вы не можете кикать старших или эквивалентных по роли или ботов` |
| Цель - сам инициатор команды, при `/ban` или `/kick` | `Что ты делаешь?` |
| `/kick` без указанной причины | `Укажите причину` |
| `/ban` на пользователе, который точно уже в бане | `Пользователь уже в бане` |
