# VoiceOwner — управление собственным голосовым каналом

> Соответствует п.8 из [base.md](../base.md). Относится к приватным голосовым комнатам, которые пользователи создают сами через бота — **подтверждено: та же сущность**, что и в [Voices.md](Voices.md) (система "опыта" и еженедельная роль "Душа компании"). Комната создаётся подключением к статичному каналу-триггеру "создать свою комнату" (см. [Voices.md](Voices.md) за деталями создания и permission overwrite владельца).

## Назначение
Позволяет владельцу приватного голосового канала самостоятельно модерировать свою комнату: выгонять нежелательных пользователей и запрещать им заходить повторно, без участия модераторов сервера.

## Видимость ответов
`/vkick`, `/vreturn` (при вызове в `#флудиславль`) — ответы **личные (ephemeral)** для slash-варианта; это осознанное исключение из общего правила "все ответы публичные" (см. [base.md](../base.md) — "Видимость ответов команд"). Для префиксных `!vkick`/`!vreturn` в канале личный ответ невозможен технически (Discord не поддерживает ephemeral для обычных сообщений) — там ответ неизбежно публичный в канале вызова, это расхождение с slash-версией принято осознанно. Вызов `/vreturn`/`!vreturn` в ЛС с ботом (по id) уже приватен по своей природе — вопрос ephemeral там неактуален. `/ban_list` — ответ всегда в ЛС независимо от способа вызова (см. таблицу команд).

## Команды
| Команда | Синтаксис | Где вызывается | Действие |
|---|---|---|---|
| `/vkick` / `!vkick` | `<id или @упоминание>` | Только находясь в своей созданной ботом приватной комнате (голос) | Кикает пользователя из приватного войса владельца (и его текстового чата) и добавляет его в личный бан-лист владельца (запрет повторного входа в ЭТУ комнату — и голос, и текст) |
| `/vreturn` / `!vreturn` | `@user` в `#флудиславль`, либо `<id>` в ЛС с ботом | Канал `#флудиславль` **или** личные сообщения с ботом | Убирает пользователя из личного бан-листа владельца, разрешая ему снова заходить |
| `/ban_list` / `!ban_list` | без аргументов | Любое место (ответ приходит в ЛС) | Бот присылает вызвавшему в личные сообщения его личный список забаненных из своего войса: для каждой записи — упоминание (`@id`) и сам id, плюс инструкция, как снять ограничение (`!vreturn @ник` в `#флудиславль` или `!vreturn id` в ЛС) |

**`/vdel` в аналог не переносится как отдельная команда** — в оригинале это была альтернатива `/vreturn` (снятие по id через ЛС), признана избыточной/deprecated. Вместо неё `/vreturn` расширена: принимает и `@упоминание` в `#флудиславль`, и `<id>` в ЛС с ботом — так что функциональность `/vdel` полностью поглощена `/vreturn`, отдельной команды для этого больше нет.

## Логика работы
1. У каждого пользователя, владеющего приватным голосовым каналом (созданным через бота), есть свой личный список "забаненных из моего войса" — отдельный от анти-работяг ([anti.md](anti.md)) и от серверных банов. Список привязан **к самому владельцу** (его id), а не к конкретному экземпляру канала — переживает пересоздание/удаление комнаты.
2. `/vkick <id или @упоминание>` (вызывается только находясь в своей приватной комнате, см. [Voices.md](Voices.md)):
   - выгоняет указанного пользователя из голосового канала владельца (disconnect) **и сразу же** выставляет точечный permission overwrite, запрещающий этому пользователю подключение к текущему каналу (подтверждено на проде — оба действия сразу, не только disconnect);
   - лишает доступа к встроенному текстовому чату этого voice-канала (штатный "Открыть чат" у любого голосового канала Discord, не отдельный канал — см. [Voices.md](Voices.md));
   - добавляет id пользователя в личный бан-лист владельца;
   - при успехе отвечает: `Пользователь @упоминание забанен в ваших комнатах.`;
   - **лимит: максимум 100 записей на владельца** — при попытке добавить 101-ю запись команда отклоняется с ошибкой `Список забаненных пользователей достиг лимита. Используйте команду banList для подробностей`, вытеснения старых записей нет.
3. **При пересоздании комнаты** (владелец заново зашёл в триггер "создать свою комнату") подтверждено, что overwrite для **недавно** забаненного (последнего добавленного в список) переносится на новый канал автоматически. Но **не подтверждено и не понятно даже автору**, переносятся ли overwrite'ы для ВСЕХ записей в личном бан-листе (потенциально до 100 штук) при каждом пересоздании, или только для части из них.

   > **Предложенное решение для новой реализации** (не наблюдение за оригиналом, а рабочая договорённость на время, пока поведение оригинала не прояснится): при пересоздании комнаты overwrite переносятся только для тех записей бан-листа, что были добавлены **в последние 24 часа**. Для более старых записей overwrite не выставляется заранее — блокировка для них обеспечивается лениво, реактивным disconnect'ом (см. вариант 1 в обсуждении) в момент попытки зайти, с простановкой overwrite по факту этой попытки. Остаётся открытым вопросом ниже — нужно сверить с реальным поведением оригинала при следующей возможности понаблюдать.
4. Снятие ограничения — двумя равнозначными способами: `!vreturn @user` в канале `#флудиславль`, либо `!vreturn <id>` в личных сообщениях с ботом (используется, когда владелец не может упомянуть пользователя — например, после просмотра списка через `/ban_list`).
5. `/ban_list` — сервисная команда просмотра: бот присылает вызвавшему в ЛС пронумерованный список (упоминание + id) всех, кого он забанил в своём войсе. Ответ идёт **только** в ЛС, без публичного запасного варианта — описание команды прямо требует, чтобы у вызвавшего были открыты личные сообщения от участников сервера. Если DM закрыт и отправка падает — это ответственность пользователя, бот на это никак не реагирует (ни в публичном канале, ни отдельным логом).
6. `/vkick`/`/vreturn` доступны **строго владельцу** комнаты — делегирования прав другим участникам нет.

## Хранимые данные
- Персональный бан-лист по каждому владельцу приватного войса (владелец → список id забаненных), с ограничением 100 записей на владельца. Привязан к владельцу, не к комнате.

## Логирование
- Не указано отдельно — вероятно, эти действия не идут в общий модераторский лог (это самообслуживание пользователей, а не модерация сервера). Уточнить.

## Обработка ошибок (точные тексты)
| Ситуация | Ответ бота |
|---|---|
| Успешный `/vkick` | `Пользователь @упоминание забанен в ваших комнатах.` |
| Лимит 100 записей достигнут | `Список забаненных пользователей достиг лимита. Используйте команду banList для подробностей` |
| Пользователь не указан / не найден на сервере | `Вы не указали пользователя или его нет на сервере` |
| Вызывающий не владелец комнаты / не находится в голосовом канале | `У вас нет прав на это действие или вы не находитесь в голосовом канале` |

## Открытые вопросы
- При пересоздании комнаты: переносятся ли permission overwrite'ы для ВСЕХ записей личного бан-листа владельца на новый канал, или только для части? Рабочая договорённость на время (окно 24 часа + ленивый fallback для остальных, см. п.3 выше) — не подтверждённое поведение оригинала, а решение для новой реализации; автор сам не уверен в точном механизме оригинала — требует дополнительного наблюдения/тестирования на проде.
